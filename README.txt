補助単位対応電卓 バージョン1.1

【使い方】
四則演算、括弧、べき乗(^)、平方根(√)、逆数(1/x)、π、ωに対応します。
接頭語: p / n / u / m / k / M / G / T（uはマイクロ）。例: 2k+500。
√と1/xは入力中の式全体または直前の結果に適用します。
fを押して周波数を入力し、=または接頭語で確定します。初期値は60 Hz。
ωは2πfです。C/Escで入力・設定を取り消します（確定済み周波数は保持）。
周波数設定中も削除できます。周波数は0以上の有限値です。
数値・演算子・括弧のキー、Enter(=)、Backspace/Delete(削除)、Esc(C)に対応。
通常のボタンはTabとSpaceでも操作できます。
デバッグ情報は折りたたみ欄から確認できます。

【精度】
有効数字4桁への丸めは表示時のみです。続きの計算では内部の結果をAnsとして使用します。
1p未満の非ゼロ値は指数表記で表示します。
内部値はJavaScriptの倍精度浮動小数点数です。任意精度の十進演算ではありません。
例: 1 / 3 = は333.3 mと表示しますが、そのまま * 3 = とすると1になります。

【構成】
index.html: 画面とバージョン表示
styles.css: レイアウトと見た目
calculator.js: 明示的な数式解析、演算、表示整形（動的コード実行なし）
app.js: 入力状態、周波数、未丸めの結果、キーボードと読み上げ
pwa.js: Service Worker登録とインストールボタン
manifest.webmanifest / service-worker.js / icons/: PWA設定とキャッシュ
calculator.test.js: 計算の回帰テスト（node --test calculator.test.js）
File - 補助単位付電卓.html: 旧版の参考資料。1.1の実行には使用しません。

【配置とPWA】
上記の実行ファイルとiconsを同じフォルダ構成で配置します。ビルドや外部ライブラリは不要です。
GitHub Pagesの場合、main / (root)など配置場所に合う設定を指定してください。
Service WorkerにはHTTPS（またはlocalhost）が必要です。
通信を優先し、通信失敗時にキャッシュを使用します。
1.1ではキャッシュ名をunit-calculator-v1.1に更新し、分割したCSS/JSも事前保存します。
既に開いている旧版は、全てのタブ・アプリを閉じて開き直すと更新されます。
対応ブラウザでは「アプリをインストール」またはブラウザメニューからインストールできます。
